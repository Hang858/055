# TLS 测试（客户端视角）验证结果

- 日期：2026-10-22
- 服务端：Ubuntu 20.04.4 LTS，内核 5.4，x86_64，`192.168.2.165`
- 客户端：Ubuntu 24.04，x86_64，`192.168.2.10`（网卡 `eno2`）
- 结论：**22 条客户端用例全部 PASS，服务端侧 TLS-2-5、TLS-1-13 均 PASS**；无 FAIL。

## 拓扑

服务端只运行服务端程序并预启动固定端点，客户端机器执行全部脚本，测试期间不登录服务端：

| 端口 | 服务端程序 | 用途 |
|---|---|---|
| 8080 | `.build/server` | 全部非 HQC 组 |
| 8181 | `.build/server_hqc` | 全部 HQC 组（8081 被测试环境其他服务占用） |
| 8082 | `.build/server -kex X25519,X25519Kyber1024Draft00` | 协商策略（TLS-1-7） |
| 8099 | `.build/tlsbench -mode server` | 性能/并发（TLS-2-1～2-4、2-7） |
| 8111 | `.build/server` + 过期证书 | 证书有效性（TLS-1-10） |

客户端以 `-addr 192.168.2.165:<端口>` 发起连接，在 `eno2` 上按 `host 192.168.2.165 and port <端口>` 抓包；断言取自客户端退出码、客户端输出与 pcap 解析结果。

## 本次改动

- `client` 增加 `-addr`、`-servername`、`-msg`、`-msg-hex`，失败路径改为非 0 退出；跨机连接与证书校验不再写死 `localhost`。
- `server` 增加 `-addr`，可在同一主机并存多个不同组配置的端点。
- `lib.sh` 增加客户端模式：只探测远端端点、在本机网卡抓包、不再启停服务端；停止抓包前等待 0.5 s，避免握手过短导致空 pcap。
- 22 条用例改为客户端视角；`server-endpoints.sh` 负责服务端端点，`run-server-side.sh` 负责服务端侧两条用例。
- 新增 `tools/tls_middlebox.py`：模拟 size-drop / first-segment-only / size-drop+loss 三种中间盒策略；`tools/tshark_check.sh` 用 tshark 解析 pcap：协商组、key_share 长度、ClientHello 记录长度与 1455 字节分包判定。
- `deploy.sh` 预编译 KEM 认证变体（`ProtocolType=QuantumSupportKemCert_KEX`），TLS-1-13 运行时覆盖四种 Sig/KEM 组合。

## 合并执行（一条命令）

`run_all.sh` 已把服务端侧两条并入：先跑 22 条客户端用例，再通过 SSH 在服务端执行 TLS-2-5、TLS-1-13，取回结果并合并到同一份 `summary.tsv`。实测合并执行 24 条全部 PASS：

| TLS-3-1～3-5 | PASS | — | 0 | 见下 |
| TLS-2-5 服务器资源消耗 | PASS | 4 | 0 | 0 |

服务端侧结果落在本次运行目录的 `server-side/` 下，结构与本机用例一致；SSH 不可用时两条保留为 `SERVER-SIDE`，其余用例照常。

### SKIP 说明

SKIP 仅表示该步骤缺少工具或不在本轮范围，不是失败：

| 用例 | 跳过项 | 原因 |
|---|---|---|
| TLS-1-8 | tshark 解析 Alert | 未装 tshark，解析步骤记 SKIP |
| TLS-1-11 | tshark 检查 Application Data | 未装 tshark，用客户端解密回显 |
| TLS-3-2 | tshark 检查密钥材料 | 未装 tshark，用客户端解密回显 |
| TLS-3-5 | Windows 实机运行 | 仅验证交叉编译 |

## 复现

服务端（一次性）：

```sh
cd /opt/pqc-tls-test
bash tls-test-scripts/server-endpoints.sh start
```

客户端（本机仓库根目录）：

```sh
sudo bash tls-test-scripts/run_all.sh
```

服务端侧两条：

```sh
cd /opt/pqc-tls-test && bash tls-test-scripts/run-server-side.sh
```
