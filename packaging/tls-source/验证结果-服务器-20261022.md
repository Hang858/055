## 部署中修正的三个问题

1. **glibc 兼容**：本机（Ubuntu 24.04）打的二进制依赖 `GLIBC_2.32/2.34`，服务器只有 2.31，直接运行报 `version GLIBC_2.34 not found`。改为在服务器上用包内补丁版 Go 重编：
   - 非 HQC：`CGO_ENABLED=0`，静态链接；
   - HQC：`CGO_ENABLED=1` + 私有 `liboqs` 静态库，`-tags pq_hqc`。
2. **pidstat 缺失**：服务器离线、未装 sysstat。本机下载 focal 版 `sysstat_12.2.0-2ubuntu0.3_amd64.deb`，scp 后**私有解压**到 `/opt/pqc-tls-test/tools/sysstat`（未进系统包数据库），测试脚本优先用系统 `pidstat`、缺失时回落到私有路径。
3. **服务端进程回收**：原 `server_start` 用子 shell 启动，`$!` 是子 shell，`server_stop` 只杀子 shell，真实 server 残留导致第二个子用例端口被占（`bind: address already in use`）。改为 `setsid` 启动、按进程组回收，已同步到包内 `lib.sh`。

## 仍为 SKIP 的步骤

- TLS-2-7 中间盒三策略：缺 `tools/tls_middlebox.py`。
