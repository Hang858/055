# 验收步骤

解压后先执行`sha256sum -c SHA256SUMS`。在能绑定本机回环端口的机器上运行`python3 smoke.py`。该脚本用压缩包中的实际程序启动演示业务服务和网关，依次验证 44/87 两档的 SM2MLKEM、旧 SM2Kyber 和 SM2HQC 双向 TLS，检查协商的密钥交换组与签名档位，并确认缺少客户端证书、档位错误和传统认证回退均被拒绝。

`validation/local-smoke.json`记录打包机上的这四组结果；`validation/gateway-tests.log`、`gateway-hqc-tests.log`和`certtool-tests.log`记录源码级测试。测试证书位于`demo/`，仅供上述联调。

厂内 Ubuntu 20.04 目标机还需复测三项：

1. 用厂内专用证书运行`bin/pqc-gateway check -config config/gateway-44.json`（或87档）。
2. 启动厂内业务服务和网关，从客户端用`probe`发送请求，确认后端收到请求，日志显示预期的`negotiated_kex`和`authenticated_signature`。
3. 分别去掉客户端证书、改错`-auth`档位、改错`-ca`或`-server-name`，确认请求失败且业务服务未收到请求。

当前归档在本地 Linux x86_64 完成构建和回环测试；Ubuntu 20.04 实机验收结果需由厂内执行后填写。
