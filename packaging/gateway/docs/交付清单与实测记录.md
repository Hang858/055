## 已执行验证

构建/测试主机为 Ubuntu 24.04 x86_64，具体内核与工具链版本见 validation/build-info.json 和 release-smoke.json。网关及五个证书工具经 file 检查均为静态 ELF x86_64，不依赖系统 glibc/liboqs。

网关模块 `go test -count=1 -v ./...` 通过：四个顶层测试（其中协议转发测试含六个组子测试），覆盖请求方法/路径/查询/正文和响应转发、转发头防伪造、证书信任/域名/有效期拒绝、传统算法和 TLS 1.2 拒绝、非法配置、HTTPS 后端 CA 校验、mTLS 有效/缺失/不可信客户端身份。测试日志中的 TLS handshake error 为负向用例预期输出，最终结果为 PASS。

交付二进制联调通过 19 项：离线安装、已安装版本、拒绝覆盖、修改包拒绝、新 PKI 生成、PKI 覆盖拒绝、相对配置路径、六个组逐组 POST 转发、错误域名拒绝、错误 CA 拒绝、非法传统组拒绝、mTLS 缺失拒绝/有效接受、后端停止后返回 502。详见 validation/release-smoke.json，每项包含退出码和输出。

五个原证书工具已从附带源码/vendor 重新编译并实际运行，样例位于 certificate-tools/examples/：

| 工具 | 实测结果 |
|---|---|
| pure-pq | 五条研究链的根自签名、中间与终端签名验证均为 true |
| sm2 | 主链 SM2/PQ 双重验证为 true，额外链验签结果保存在完整日志 |
| x509-multi | 标准 RSA X.509 链验证成功；这不等于客户端已验证其全部自定义 PQ 扩展 |
| gen-pq-chain | 样例外部公钥导入、签发及内置验证通过 |
| gen-sm2-chain | 样例外部公钥导入、签发及内置验证通过 |

日志见 validation/*-generation.log 和各样例目录 generation.log。示例私钥不是正式部署身份。
