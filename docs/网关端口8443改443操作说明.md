# 网关端口 8443 改 443 与停用操作说明

日期：2026-10-29
状态：待执行（服务器当前断网，以下为恢复链路后的操作步骤）
适用主机：`192.168.2.165`
安装目录：`/opt/pqc-gateway-hybrid`

## 1. 结论

- **8443 可以停**：停 44 档只影响 8443，不影响 8444/8445。
- **8443 可以改 443**，但不能直接改，需要同时满足：
  1. 443 端口空闲；
  2. 网关以系统级 systemd 运行，并授予 `CAP_NET_BIND_SERVICE`。
- 当前 443 有别的服务在监听，不是网关，所以**现在不能直接改**。
- 三方模板里的 `tls.port` 是 SSH 端口 22，**不要改成 443**；443 是 TLS 业务端口，不在这个字段里。

## 3. 停 8443

### 3.1 用户级服务

```bash
/opt/pqc-gateway-hybrid/scripts/gwctl.sh stop 44
```

或：

```bash
export XDG_RUNTIME_DIR=/run/user/$(id -u)
systemctl --user stop pqc-gateway-hybrid
```

### 3.2 系统级服务（如果已安装）

```bash
sudo systemctl stop pqc-gateway-hybrid
```

### 3.3 禁止开机自启

```bash
# 用户级
systemctl --user disable pqc-gateway-hybrid

# 系统级
sudo systemctl disable pqc-gateway-hybrid
```

### 3.4 验证

```bash
ss -ltn | grep ':8443'    # 应无输出
```

87、ECDSA、后端不受影响，8444/8445/9000 仍在监听。

## 4. 改 443

### 4.1 先确认 443 是谁

```bash
sudo ss -ltnp | grep ':443'
sudo lsof -iTCP:443 -sTCP:LISTEN
```

根据输出确认是 nginx、Apache、某个业务程序还是别的服务。

### 4.2 处理 443 占用

**方案 A：443 上的服务不需要**

```bash
sudo systemctl stop <服务名>
sudo systemctl disable <服务名>
```

**方案 B：443 上的服务还需要**

不能直接把网关绑到同一个 `0.0.0.0:443`。可选：

- 把原服务迁到别的端口或别的 IP；
- 保留网关 8443，前端用 TCP 转发/负载均衡把 443 转到 8443；
- 如果原服务只绑某个具体 IP，网关可以绑另一个 IP 的 443，但不能和 `0.0.0.0:443` 共存。

**方案 C：不改**

继续用 8443，只把三方测试的访问地址写成 `https://192.168.2.165:8443/`。

### 4.3 备份并修改配置

```bash
P=/opt/pqc-gateway-hybrid
cp "$P/config/gateway-managed.json" "$P/config/gateway-managed.json.bak-$(date +%Y%m%d-%H%M)"
python3 - <<'PY'
import json
p = "/opt/pqc-gateway-hybrid/config/gateway-managed.json"
with open(p, encoding="utf-8") as f:
    d = json.load(f)
d["listen"] = "0.0.0.0:443"
with open(p, "w", encoding="utf-8") as f:
    json.dump(d, f, ensure_ascii=False, indent=2)
    f.write("\n")
PY
"$P/bin/pqc-gateway" check -config "$P/config/gateway-managed.json"
```

只改 `listen`，证书、`auth`、`kex`、`upstream`、`server_name` 都不动。

### 4.4 安装系统级服务并授予绑定权限

**用户级 systemd 不能绑定 443**，必须用系统级 unit。当前系统级 unit 模板在：

```text
/opt/pqc-gateway-hybrid/systemd/pqc-gateway-hybrid.service
```

在 `[Service]` 段加两行：

```ini
AmbientCapabilities=CAP_NET_BIND_SERVICE
CapabilityBoundingSet=CAP_NET_BIND_SERVICE
```

完整 `[Service]` 参考：

```ini
[Service]
Type=simple
User=xgs
Group=xgs
WorkingDirectory=/opt/pqc-gateway-hybrid
ExecStartPre=/opt/pqc-gateway-hybrid/bin/pqc-gateway check -config /opt/pqc-gateway-hybrid/config/gateway-managed.json
ExecStart=/opt/pqc-gateway-hybrid/bin/pqc-gateway serve -config /opt/pqc-gateway-hybrid/config/gateway-managed.json
Restart=on-failure
RestartSec=3
UMask=0077
NoNewPrivileges=true
PrivateTmp=true
AmbientCapabilities=CAP_NET_BIND_SERVICE
CapabilityBoundingSet=CAP_NET_BIND_SERVICE
```

然后执行安装脚本（会停用户级服务、装系统级 unit）：

```bash
sudo /opt/pqc-gateway-hybrid/scripts/install-managed-systemd.sh
```

或只重载并重启 44 档：

```bash
sudo systemctl daemon-reload
sudo systemctl restart pqc-gateway-hybrid
```

### 4.5 验证

```bash
ss -ltnp | grep ':443'
sudo systemctl status pqc-gateway-hybrid --no-pager
/opt/pqc-gateway-hybrid/bin/pqc-gateway probe \
  -url https://192.168.2.165/ \
  -server-name gateway.factory.local \
  -ca /opt/pqc-gateway-hybrid/certs/44/root.crt \
  -auth sm2-mldsa-44 -kex SM2MLKEM512
```

预期：`http_status=200`、`certificate_verified=true`、`negotiated_kex=SM2MLKEM512`。

从其他机器访问时，URL 不再带 `:8443`：

```text
https://192.168.2.165/
```

### 4.6 回滚到 8443

```bash
P=/opt/pqc-gateway-hybrid
cp "$P/config/gateway-managed.json.bak-<时间>" "$P/config/gateway-managed.json"
# 从 systemd unit 中删除 AmbientCapabilities / CapabilityBoundingSet 两行
sudo systemctl daemon-reload
sudo systemctl restart pqc-gateway-hybrid
ss -ltn | grep ':8443'
```

如果回退到用户级服务，先停系统级、再启用用户级：

```bash
sudo systemctl disable --now pqc-gateway-hybrid
export XDG_RUNTIME_DIR=/run/user/$(id -u)
systemctl --user enable --now pqc-gateway-hybrid
```

## 7. 注意

- 不要用 `setcap` 给二进制加权限来绕过：当前 unit 带 `NoNewPrivileges=true`，文件 capability 会被忽略，而且每次替换二进制都会丢失。
- 不要以 root 直接跑网关来图省事；用系统级 unit + `CAP_NET_BIND_SERVICE` 更可控。
- 443 是通用 HTTPS 端口，改过去之前先确认没有别的业务依赖原 443 服务。
- 如果原 443 是 nginx/Apache，停掉前先确认它是否还承载别的站点。
