## 3. 待办

### 3.1 持久化删除 ens41f1 的 192.168.2.166（优先）

当前**运行态**已经把 `ens41f1` 的 `192.168.2.166/24` 去掉，所以 IPv4 回程走 `ens41f0`，SSH 正常。但 `/etc/netplan/00-installer-config.yaml` 里仍然配置着 `.166`，重启或 `netplan apply` 会把它加回来，IPv4 会再次出现“能 ARP、TCP 超时”的问题。

在服务器上执行（需要 sudo）：

```bash
sudo cp /etc/netplan/00-installer-config.yaml /etc/netplan/00-installer-config.yaml.bak-20261029
sudo python3 - <<'PY'
from pathlib import Path
p = Path('/etc/netplan/00-installer-config.yaml')
s = p.read_text()
block = '''    ens41f1:
      dhcp4: false
      addresses: [192.168.2.166/24]
      gateway4: 192.168.2.254
      nameservers:
        addresses: [114.114.114.114, 8.8.8.8]
'''
if block not in s:
    raise SystemExit('ens41f1 block not found, 手工检查')
p.write_text(s.replace(block, ''))
PY
sudo netplan apply
```

执行后确认：

```bash
ip -br addr show ens41f1     # 不应再有 192.168.2.166
ssh xgs@192.168.2.165 hostname
```

如果 `ens41f1` 后续还要接别的网段，就把 `.166` 换成那个网段的地址，不能继续和 `ens41f0` 同为 `192.168.2.0/24`。

### 3.2 系统级 systemd（三方工具用 sudo 时）

当前是用户级服务。如果三方工具通过 `sudo systemctl restart pqc-gateway-hybrid` 管理，执行一次：

```bash
ssh -t xgs@192.168.2.165 'sudo /opt/pqc-gateway-hybrid/scripts/install-managed-systemd.sh'
```

脚本会停用户级服务、安装 `/etc/systemd/system/pqc-gateway-hybrid*.service` 并启动。

### 3.3 其他

- 纯 `X25519` 不支持；ECDSA 档现在用 `X25519Kyber768Draft00`。如果三方测试要求纯 X25519，需要改代码并重新打包。
- 当前没有启用双向认证（没有 `client_ca`）。需要 mTLS 时把 `/opt/pqc-gateway-hybrid/certs/44/root.crt` 配成 `client_ca`，客户端带 `/opt/pqc-gateway-hybrid/offline/44/client.*`。
- `auth_profiles` 是三方工具自己的配置段，不是网关 JSON 的格式；网关一次只认一个 `auth`，现在用三个进程/端口覆盖三档。
- 工作区有未提交修改，打包前确认是否要提交。

## 4. 后续调试与交付流程

原则：**服务器只作为运行/验证环境，不在上面改源码**。所有改动在本地仓库完成，打包后交付。

### 4.1 本地构建

依赖本仓已有的补丁工具链：

- `.build/go`：补丁 Go 1.22.12
- `.build/gopath/pkg/mod/golang.org/toolchain@v0.0.1-go1.25.1.linux-amd64`
- HQC 需要 `.build/liboqs-gateway-hqc/lib/liboqs.a`

构建命令：

```bash
cd /home/hangzhang/work/055
python3 packaging/build_hybrid_runtime_release.py --replace
```

输出：

```text
dist/pqc-gateway-hybrid-mlkem-ubuntu20.04-amd64-20261013.zip
sha256 <...>
```

构建脚本会跑 `go test`/`go vet`，并生成 `SHA256SUMS`、`demo` 证书和 `validation/` 日志。版本号目前写死在脚本的 `NAME` 和 `-ldflags -X main.version=...`，换版本时先改这两处。

### 4.2 交付到远端

```bash
scp dist/pqc-gateway-hybrid-mlkem-ubuntu20.04-amd64-20261013.zip \
  xgs@192.168.2.165:/home/xgs/incoming/
```

在服务器上解压到**新目录**，不要覆盖现有 `/opt/pqc-gateway-hybrid` 的证书和配置：

```bash
cd /home/xgs/incoming
unzip -q pqc-gateway-hybrid-mlkem-ubuntu20.04-amd64-20261013.zip
```

只更新二进制（保留现有 certs/config）：

```bash
sudo install -m 755 pqc-gateway-hybrid-mlkem-ubuntu20.04-amd64-20261013/bin/pqc-gateway \
  /opt/pqc-gateway-hybrid/bin/pqc-gateway
sudo install -m 755 pqc-gateway-hybrid-mlkem-ubuntu20.04-amd64-20261013/bin/pqc-gateway-hqc \
  /opt/pqc-gateway-hybrid/bin/pqc-gateway-hqc
sudo install -m 755 pqc-gateway-hybrid-mlkem-ubuntu20.04-amd64-20261013/bin/pqc-certtool \
  /opt/pqc-gateway-hybrid/bin/pqc-certtool
```

如果配置格式也变了，再更新 `config/gateway-managed*.json`。重启并验证：

```bash
export XDG_RUNTIME_DIR=/run/user/$(id -u)
systemctl --user restart pqc-gateway-hybrid pqc-gateway-hybrid-87 pqc-gateway-hybrid-ecdsa
/opt/pqc-gateway-hybrid/scripts/gwctl.sh status 44
```

用本地 `probe` 或服务器上的 `probe` 复测 8443/8444/8445 三档。

### 4.3 回滚

覆盖二进制前先备份：

```bash
sudo cp /opt/pqc-gateway-hybrid/bin/pqc-gateway /opt/pqc-gateway-hybrid/bin/pqc-gateway.bak-$(date +%Y%m%d-%H%M)
```

回滚就是恢复 `.bak` 并重启服务。

## 6. 风险提示

1. `ens41f1` 的 `.166` 还没从 netplan 里删除，重启会复发 IPv4 超时。
2. 用户级 systemd 依赖 `Linger=yes`；如果用户管理器没起来，服务不会启动。系统级服务装好后不再依赖这一项。
3. 网关只支持单档 `auth`，三方工具的 `auth_profiles` 不能在同一个进程里同时生效；需要三端口或工具侧改写配置后重启。
4. 纯 X25519 不支持，ECDSA 档是混合 KEX。
5. 当前未启用 mTLS，只验证服务端证书。
